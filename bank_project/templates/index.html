💡 How AnshPunji Works

1️⃣ Data Ingestion

Reads transactional CSV from bank dataset or uploaded file and prepares a normalized edge list for analysis.

2️⃣ Smart Pattern Detection

Detects directed cycles and suspicious bursts using graph traversal and feature scoring.

3️⃣ Visualization & Reporting

Produces per-account risk scores, a suspicious-accounts CSV, and a network graph — all shown inline for quick review.
